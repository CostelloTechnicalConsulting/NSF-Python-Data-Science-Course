# NSF-Python-Data-Science-Course
Repository for course materials for Python Data Science course using NSF data. All necessary exercise files and solution files are included in this repository.

### To obtain the files for this course
#### Zip file method
Click the green "Code" button at the top right of this screen and select "Download ZIP" from the menu. After the zip file has downloaded, extract it somewhere convenient and open the files with the IDE of your choice (we recommend Visual Studio Code).

#### git clone method
If you have the git command line tool, from a command line run the following command:

    git clone https://github.com/CostelloTechnicalConsulting/NSF-Python-Data-Science-Course.git {path_to_target_directory_of_your_choice}

(If you don't have the git command line tool, you can download and install from here: https://git-scm.com/download/win)

### To download the data files for this course
This course uses some large data files that cannot be stored in GitHub. Once you've cloned this repository, the files can be downloaded by running the notebook named download-all-pkl-files.ipynb in the resources directory.
